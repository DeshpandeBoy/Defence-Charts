# E1.4 — Package reliability gates

## Objective

Add offline release verification for all six published packages: publint, are-the-types-wrong,
package content, CSS subpath resolution, packed React/Next/RSC/Vite consumers, and explicit
no-network behavior.

## Current state

The implementation is complete and ready for coordinator review. The gate packs each package
from its package directory, extracts the tarballs into a temporary consumer, validates the
published export map and declaration pairing, resolves all published CSS subpaths, runs
publint 0.3.24 and @arethetypeswrong/cli 0.18.5 in ESM-only mode, then runs the existing E1.3
consumer proof with COREPACK_ENABLE_NETWORK=0, npm offline flags, and a Node network-deny preload.

The package command is named verify:packages and is included in the root verify chain. It builds
before checking artifacts, so it is reproducible from a clean checkout after an offline install.
Failures preserve the temporary packed-artifact root for inspection.

  not yet materialized and the rsc fixture reported next: command not found. The exact offline
  frozen install above repaired the worktree; the subsequent build, verify:packages, and verify
  all passed.

  used. Verification was run through Node 24 as required by the repository runtime contract.
- ESM-only attw intentionally ignores CJS/node10 resolutions. The package's ESM and bundler rows
  pass; CSS is not a JavaScript/type entrypoint and is separately resolved against packed dist.
