## Current repository setup

ShiftCharts is not published yet. Inside this monorepo, applications consume packages through pnpm
workspace links:

```json title="package.json"
{
  "dependencies": {
    "@shiftcharts/core": "workspace:*",
    "@shiftcharts/primitives": "workspace:*",
    "@shiftcharts/react": "workspace:*",
    "@shiftcharts/tokens": "workspace:*"
  }
}
```

Run the pinned package manager from the repository root:

```bash
pnpm install
pnpm --filter @shiftcharts/docs dev
```

## After npm publishing

The public package names are final. These commands become installable after the first npm release:

```bash
# Pure decisions and geometry
pnpm add @shiftcharts/core

# Known-size, server-safe rendering
pnpm add @shiftcharts/core @shiftcharts/primitives @shiftcharts/tokens react

# Automatically measured responsive rendering
pnpm add @shiftcharts/core @shiftcharts/primitives @shiftcharts/react @shiftcharts/tokens react react-dom
```

Do not put these commands into production automation until the packages are public.

## Required styles

The component entry points do not pull CSS into your bundle. Import the layers explicitly so your
application controls cascade order:

```ts
import '@shiftcharts/tokens/theme.css'
import '@shiftcharts/primitives/chart.css'
import '@shiftcharts/react/auto-chart.css'
```

`chart.css` is needed for both `Chart` and `AutoChart`. `auto-chart.css` is needed only for the
client measurement wrapper.

## Runtime requirements

- React 19.
- ESM-aware bundler.
- Node 22, 24, or 26 and newer for repository tooling. Node 25 is unsupported.
- A real height for every `AutoChart` container.

Next.js is a consumer convention and test fixture, not a ShiftCharts dependency. Nothing under
`packages/` imports from `next`.
