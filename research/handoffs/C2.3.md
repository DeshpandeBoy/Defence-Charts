## Decisions and assumptions

| Item | Class | Effect |
|---|---|---|
| Fetching and retry remain host-owned | locked architecture | State UI receives an already-decided state and optional host content; it does not call APIs, manage async state, or expose retry callbacks |
| Geometry must remain stable across states | task acceptance | All four states render through one wrapper and fixed content/status/message/label/description/action slots; the state surface fills and clips within its parent region |
| Stale content remains host-controlled | research/83 visual interaction architecture | The host decides whether to pass previously loaded content for `stale`; the component only supplies a compact status overlay and host action slot |
| State UI is generic widget chrome | task boundary | No chart type, datum, planner, or data-fetching imports are allowed |
