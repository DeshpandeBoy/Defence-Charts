## Decisions and assumptions

| Item | Class | Evidence | Effect |
|---|---|---|---|
| KPI has no dedicated mark kind | Locked architecture | `research/40-chart-plan.md` §8; `CR-D00` | Compose value band with `none`/line/horizon marks; do not add a redundant mark union member |
| Sparkline is line with axes suppressed | Locked architecture | `packages/core/src/plan.ts` and `40-chart-plan.md` §4.2 | KPI Strip uses the existing line mark and does not create a `sparkline` type |
| Unit, target, and status belong to canonical series metadata | Implementation contract | D3.1 acceptance and `10-responsive-ladder.md` KPI table | Add optional serialisable metadata; existing line/donut callers remain source-compatible |
| Status is visible text plus table data | Accessibility contract | D3.1 objective; color-only status is prohibited | CSS may theme status, but meaning survives forced colors and no-CSS output |
| Target is numeric and may be absent | Data contract | `Series` already owns actual values; no target field existed | Non-finite/missing target is rendered as unavailable, never inferred |
