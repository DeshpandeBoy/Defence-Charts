# SB-009 — Enable motion in sandbox chart pages

## Objective

Make the regular sandbox chart studio and interaction examples exercise the shipped
`@shiftcharts/motion` boundary. Keep the default core CSS motion available and add an explicit
cinematic mode for interruptible geometry transitions.

## Acceptance criteria

- [x] Chart studio exposes Core and Cinematic motion modes.
- [x] Chart studio preview and size-ladder charts are wrapped by `MotionBoundary`.
- [x] Interaction examples use the selected sandbox motion mode.
- [x] Core mode preserves existing CSS plan transitions; Cinematic uses the real motion package.
- [x] `prefers-reduced-motion` remains respected by the motion package.
- [x] Sandbox typecheck/build, focused motion tests, browser resize verification, and
  `git diff --check` pass.

## Decisions

| Item | Class | Effect |
|---|---|---|
| Motion is sandbox-controlled | scope | No change to the public `AutoChart` default or package architecture. |
| Cinematic is opt-in in the sandbox | motion contract | Existing core behavior remains available; users can select the interruptible path explicitly. |
| The wrapper uses `display: contents` | existing package behavior | The motion boundary does not change measured chart geometry or the `AutoChart` resize owner. |
