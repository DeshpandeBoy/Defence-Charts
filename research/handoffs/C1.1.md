# C1.1 — Build the controlled grid engine wrapper

## Objective

Add the first project-owned client wrapper around `react-grid-layout/react`. The wrapper owns the
public controlled layout and callback contract, converts RGL callback values back to immutable
`@gx/core` snapshots, preserves widget IDs as React keys, and exposes explicit edit/read-only modes.
It must not know chart types, chart data, or chart rendering semantics.

## Acceptance criteria

- [ ] Public props use project-owned `WidgetLayoutInput`/`LayoutSnapshot`/`WidgetId` values and do
  not leak RGL types.
- [ ] RGL React UI is imported only from `react-grid-layout/react`; the pure adapter remains on
  `react-grid-layout/core`.
- [ ] `WidgetGrid` is controlled by the host's layout input and emits serialisable layout snapshots.
- [ ] Drag and resize callbacks expose stable widget IDs and project-owned immutable values.
- [ ] `mode="edit"` enables drag/resize and `mode="read-only"` disables both explicitly.
- [ ] Content is supplied through a render callback keyed by the stable widget ID; no chart-type
  knowledge enters the grid package.
- [ ] Component tests prove initial props, controlled updates, stable child/layout keys, mode
  behavior, and callback conversion.
- [ ] Grid typecheck, focused tests, build, dependency boundary, and `git diff --check` pass.
