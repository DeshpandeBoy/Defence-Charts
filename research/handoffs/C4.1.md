## Known failures and blockers

- No browser failure or blocker occurred in this checkpoint.
- `WidgetGrid` currently exposes the repository's default RGL `se` resize handle only. The gate
  explicitly verifies that handle in both east-south and west-north delta directions; it does not
  claim unsupported corner handles.
- `WidgetGrid` excludes `button` descendants from its drag-start selector, while `WidgetShell`'s
  built-in drag handle is a button. The fixture therefore adds a direct sibling, non-button
  `data-gx-pointer-handle` bridge inside each real shell slot to exercise the actual WidgetGrid
  pointer path. This proves grid mechanics and must not be read as proof that the built-in shell
  button starts a drag.
- CSS `zoom` is tested with the fixture's fixed `960px` grid width. Chromium measured a known
  `232px` horizontal ancestor overflow under `zoom:1.25`; the gate records
  `zoom:pass-fixed-width-overflow:232px` and still enforces IDs, no overlap, containment, and no
  outer-box growth. Other overflow/transform/RTL/flex/grid cases had no scroll growth.
- Touch coverage is a Playwright touchscreen tap probe: a tap on the pointer bridge must not start
  a drag, and IDs/geometry remain stable. A full touch drag is an environment/API limitation and
  is not claimed by this gate.
- Reduced-motion and forced-colors contexts both passed locally. No missing-Chromium skip was
  observed; if it occurs, the remedy is `pnpm exec playwright install chromium` (or
  `pnpm exec playwright install --with-deps chromium` when shared libraries are missing), and CI
  will fail because `GX_REQUIRE_BROWSER=1` is set.

## Coordinator P0 follow-up — keyboard cancellation race

The hosted C4.1 rerun on 2026-08-26 exposed a real controlled-layout race: after keyboard Escape
restored the prior snapshot, RGL could deliver stale preview geometry through `onLayoutChange` and
overwrite the restoration. `WidgetGrid` now holds the serialized cancellation snapshot until RGL
reports that exact restored layout; stale callbacks are ignored, while a later real interaction is
accepted. `WidgetGrid.test.tsx` includes a regression covering stale, restored, and subsequent
legitimate callbacks.
