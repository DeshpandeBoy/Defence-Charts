# E1.2 — Package metadata and dependency correctness

## Objective

Make all six package manifests publishable and evidence-bounded, keep runtime dependency
declarations aligned with actual imports, and prove packed tarballs carry their public metadata,
README, MIT licence, copyright notice, built entrypoints, and non-workspace dependency declarations.

- Branch: codex/E1.2-package-metadata

- Last known green upstream check: E1.1 built-artifact proof on the base

## Implementation

- Removed private publication blocking from all six package manifests and added public npm access,
  repository URL/directory, homepage, issue tracker, Node engine, and package file metadata.
- Added package-local README files describing only the exports currently present. In particular,
  @gx/react no longer advertises future tooltip, crosshair, brush, or legend behavior.
- Added one exact copy of the root MIT LICENSE to every published package and made the package
  metadata/tarball gate compare every copy byte-for-byte with the root notice.
- Removed the unused @gx/react runtime dependency from @gx/grid.
- Moved jsdom from @gx/testing devDependencies to dependencies because its exported markup parser
  imports it at runtime; removed the unused @gx/core dependency from @gx/testing.
- Added scripts/check-package-metadata.mjs and its Vitest test. The gate checks source manifests,
  dependency/peer keys, sideEffects, public export roots, README/LICENSE/dist inclusion, offline
  pnpm pack output, packed dependency replacement, and tarball content.
- Updated pnpm-lock.yaml only for the two real dependency changes.
