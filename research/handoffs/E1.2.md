- Confirm @gx/react description advertises only exported behavior.

- Run focused metadata/tarball checks, package build if needed, dependency and boundary checks, and git diff --check.
- Update this handoff to handoff with exact commands, results, changed paths, current commit, failures, remaining work, and resume command. Commit code, tests, and handoff together.
