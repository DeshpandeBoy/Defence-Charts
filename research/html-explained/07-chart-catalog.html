What is not silently fixed

VT-003 needs a data-model decision so donut/funnel categories can have real names instead of raw indexes. VT-009–VT-011 are lower-confidence questions about anomaly hints, middle heatmap labels, and strip-key consistency.

Plain-English meaning: the chart families exist and can run, but the release still needs a person-focused pass. We do not mark these issues fixed until the code and regression checks actually change.

Selection guide

Pick a family from the question.

The data shape matters, but the reader’s question comes first. This is a product decision aid, not a complete recommendation engine.

How is it changing?

Line or area for a continuous/time-indexed trend. At tiny sizes, say the latest value and direction instead of drawing a dishonest micro chart.

How do parts compare?

Bar for discrete categories; donut when part-to-whole composition is genuinely the question and the category count stays scannable.

Do two variables relate?

Scatter. Keep point identity, axes, and outlier labeling explicit; do not silently drop observations.

Where does a process leak?

Funnel, with stage names and drop-off semantics. Horizontal orientation is often more honest when height is limited.

What is the current number?

KPI for the primary value. Add a delta and basis only when they fit the information budget.

Which cells are active?

Heatmap for repeated categorical/time cells. Aggregate by an explicit unit when cell size becomes unreadable.
