## Decisions and assumptions

| Item | Class | Evidence | Effect |
|---|---|---|---|
| Preserve typography scale | locked design | `DESIGN.md` fixes ranks A–E at 13/12/11/11/10 px | Improve hierarchy by applying the ranks correctly; do not copy Highcharts' 19.2/12.8 px literals. |
| Chrome stays inside SVG | architecture | `AutoChart` documents that a normal-flow sibling changes the measured box | Reserve/render title, subtitle, and axis-title bands inside the existing frame/SVG. |
| No DOM text measurement | locked decision 10 | planner/RSC contract | Use the existing font metrics and deterministic candidate scoring. |
| Highcharts is a quality reference, not an API template | product positioning | decisions and user request | Match comprehension and finish while preserving ShiftCharts' ladder and package boundaries. |
| Title capability derives from the finished line rung | scoped architecture | global `ChartPlan` expansion would force unrelated family churn | Panel enables title; Canvas/Stage add subtitle; the same derived chrome is used by rung sizing and frame reconstruction. |
| Full series text precedes truncation | visual inspection + existing metrics | the old eight-character cap produced avoidable `Mainten…` | Search contained low-collision points first; apply `seriesLabelMaxChars` only if no full candidate fits. |
| Fixed domain bypasses `nice()` | semantic contract | a fixed endpoint changed by `nice()` is not fixed | Tick generation stays nice; scale endpoints stay exact. |
