title: A chart should change what it says, not only how small it gets
description: GX plans a different, honest chart for the space a widget actually has.
---

GX is a presentational React chart library built around a **responsive information ladder**.
When a widget gets smaller, GX can remove an unreadable axis, replace a line with a horizon
encoding, move a legend, or state one value directly. It does not merely squeeze the same chart.

<Callout type="warn" title="Private workspace today">
  The implementation through milestone A5 exists, but the packages are still private and
  `@gx/*` is a placeholder scope. Examples on this site compile inside this monorepo. Public npm
  installation waits for the project name and scope decision.
</Callout>

## The whole system in one path

| Owner | Receives | Produces |
| --- | --- | --- |
| Your application | API rows, query results, local state | Canonical `Series[]` |
| `@gx/core` | Size, data shape, policy, overrides | Serializable `ChartPlan` |
| `@gx/primitives` | Plan, canonical values, same size context | Accessible SVG and data table |
| `@gx/react` | A container with a real size | Measurement, planning, then `<Chart>` |

The planner never sees actual values. `describeShape(data)` derives the counts and traits it
needs; `resolveFrame(plan, data, ctx)` is where values become scales and coordinates.
