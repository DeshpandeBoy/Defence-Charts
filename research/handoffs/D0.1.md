## Allowed write set

- central core/primitives planner and renderer types
- immutable built-in dispatcher or renderer registry
- focused tests and docs for the seam
- this handoff file

Do not add a global mutable plugin registry, runtime side-effect registration, a generic mega-renderer, new chart-family behavior, package manifests, lockfiles, unrelated CSS, or other handoffs. Central exports and the master ledger are coordinator integration points; request any required central export additions in the handoff rather than editing unrelated release files.

## Acceptance criteria

- Family-local planner and mark contracts are explicit and serializable where they cross core boundaries.
- Built-in registration is immutable, statically analyzable, and does not rely on runtime side effects.
- Existing line/area behavior and plan output remain unchanged.
- Tree-shaking and RSC gates continue to pass; no new browser dependency enters core or primitives.
- Add an add-a-family checklist and fixture convention without claiming future family behavior.
- Run focused seam tests plus typecheck, lint, API, tree-shake, RSC/boundary, build, and git diff --check.
- Update this handoff to handoff with exact evidence, changed paths, current commit, failures, remaining work, and resume command. Commit code, tests, and handoff together.
