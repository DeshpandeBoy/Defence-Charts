# Donut family

The donut family uses the shared plan ladder for chrome and interaction, then replaces the plot
mark with an arc. The frame owns value-aware aggregation because `planChart()` is intentionally
data-blind. Canvas and Stage make the visible `Other` bucket explicit; the renderer never silently
drops categories or falls back to a line.

The current contract is a non-negative parts-of-a-whole series. The existing data table remains the
non-color/static equivalent for assistive technology.
