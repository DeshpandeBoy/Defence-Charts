# D5.1 — heatmap family

## Objective

Ship an explicit, pure heatmap planner and hook-free renderer for an activity-style grid. The
responsive contract is not a smaller version of the same chart: Tile replaces the grid with a
total, Strip keeps only the last N weeks without labels, Panel shows the full weekday/month grid,
Canvas adds a readable intensity legend and spelled-out weekday labels, and Stage adds per-cell
values on hover plus streak annotations. When the nominal cell floor cannot be maintained, the
plan records weekly temporal binning; it never silently shrinks cells until the data is unreadable.
