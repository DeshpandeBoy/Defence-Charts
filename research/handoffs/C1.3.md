# C1.3 — Add resize preview and committed callback contract

## Objective

Define and wire a project-owned drag/resize lifecycle. Start and preview events may be frequent;
the host receives exactly one serialisable commit for a completed interaction. Cancellation returns
the initial snapshot and never saves a pointer-frame preview.

## Acceptance criteria

- [ ] Public lifecycle values are serialisable and addressed by stable `WidgetId`.
- [ ] Start, preview, cancel, and commit transitions are explicit and deterministic.
- [ ] Preview callbacks may fire per pointer frame, but the committed layout callback fires once per
  interaction and does not save every preview.
- [ ] Cancellation returns the initial layout snapshot and clears the active session.
- [ ] WidgetGrid exposes the lifecycle without leaking RGL callback types.
- [ ] Tests cover drag and resize session identity, preview/commit/cancel behavior, duplicate commit
  suppression, controlled host updates, and immutable payloads.
- [ ] Grid typecheck, focused tests, build, dependency boundary, and `git diff --check` pass.
