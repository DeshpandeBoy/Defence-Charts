## Objective

Add a composable widget shell with header/title/context/action slots, a scoped content region, an
optional footer, and an explicit drag handle. The grid must start drag only from that handle and
must cancel drag initiation from content and controls.

## Acceptance criteria

- [ ] Public shell props expose header/title/context/action/content/footer regions without chart-type
  knowledge.
- [ ] The shell renders an accessible named region and a discoverable drag handle with a stable
  label; the content region is marked as grid-drag cancel scope.
- [ ] WidgetGrid configures RGL to use the shell handle and cancel selectors for controls/content.
- [ ] Per-widget theme scope is expressed by a data attribute/custom-property hook, not a runtime
  style provider or second styling system.
- [ ] Tests cover slot order, omission of optional slots, accessible handle semantics, scoped theme
  attributes, and the drag handle/cancel configuration.
- [ ] Grid typecheck, focused tests, build, dependency boundary, and `git diff --check` pass.
