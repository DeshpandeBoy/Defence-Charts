# Claude research proposals

Each Claude research task writes one uniquely named file here using the contract in
[`../../92-claude-research-workstream.md`](../../92-claude-research-workstream.md).

Files in this directory are evidence proposals, not locked decisions and not proof of implemented
features. The coordinator reviews each proposal, reproduces repository-dependent claims, and then
either rejects it, defers it, records a clarification, or promotes it into the canonical research
and decision register.

Do not overwrite another task's file. Use the assigned task ID as the filename prefix.
