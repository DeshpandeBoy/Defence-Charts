## Decisions and assumptions

| Item | Class | Evidence | Effect |
|---|---|---|---|
| Benchmark stays in sandbox | locked architecture | Core remains pure; React interaction preparation is client-owned | No package behavior or public export changes; the sandbox reads the current interaction implementation directly for baseline evidence. |
| Dense cases are not mounted as visual charts | implementation | Current scatter renderer throws for `renderer: 'canvas'` | The page measures the plan/frame/index path without presenting an unfinished Canvas renderer as shipped. |
| Deterministic generated data | implementation | Reproducible comparisons need stable input | The same point counts and series structure can be rerun across machines; timings remain machine/browser dependent. |
