# SB-010 — sandbox dashboard composition

## Objective

Build the sandbox's final-product V1 dashboard demo at `/dashboard`: all ten shipped chart
families, a controlled 12-column responsive bento layout, 2x2 and 4x4 examples, footprint
variation previews, drag/resize controls, keyboard editing, widget states, theme and motion
controls, and a resettable layout readout.

- `apps/sandbox/src/DashboardPage.tsx`

## Acceptance criteria

- `/dashboard` is reachable from sandbox navigation and browser history.
- The dashboard renders all ten shipped chart types in stable, labelled widget shells.
- The primary layout includes real 2x2 and 4x4 footprints plus broader bento sizes.
- The grid uses `@shiftcharts/grid` with controlled layout commits, edit/read-only mode, pointer
  drag/resize, keyboard move/resize, and reset.
- Each chart receives its authoritative `gridSize` footprint and is wrapped in the current motion
  boundary; no parallel chart renderer or layout engine is introduced.
- A visible state selector exercises `WidgetStates`; theme and motion controls remain usable.
- Dashboard-specific presentation uses the existing token system and does not edit package CSS.
- Typecheck, build, relevant grid tests, `git diff --check`, and browser verification are recorded.
