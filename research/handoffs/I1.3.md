## Implementation checkpoint

The client layer is implemented over the existing pure frame and placement contracts. It portals
an absolutely positioned interaction layer into the existing chart figure after client layout,
so the measured wrapper still has one normal-flow child and server markup remains unchanged.
Interaction is absent for the none plan, fixed for Strip/Panel plans, and fluid only for
Canvas/Stage plans. Active datum identity is keyed by Series.id plus the original source point
index, including source arrays with null gaps. The crosshair is inside an SVG clipPath matching
the frame plot rectangle. Tooltip content has role=tooltip, aria-describedby from the focusable
surface, and a role=status live equivalent. Escape, hover leave, tap lock/toggle, arrow/Home/End
navigation, and resize-preserved identity are covered.
