## Decisions and assumptions

| Item | Class | Effect |
|---|---|---|
| RGL supplies pointer mechanics only | verified dependency evidence | Keyboard behavior is project-owned and drives the same controlled layout contract |
| Constraint reuse is mandatory | locked implementation boundary | Keyboard does not mutate x/y/w/h directly without `applyGridProposal` validation/compaction |
| Focus is restored to the initiating stable control | accessibility contract | Escape and commit do not strand focus on a removed/transformed transient element |
| Move and resize are separate labelled controls | generic host-controlled API decision | The host can place any widget content beneath two discoverable edit affordances without chart knowledge |
| Resize arrows change width/height from the far edge | task-local keyboard mapping | Left/Up reduce `w`/`h`; Right/Down increase them; min/max/bounds remain enforced by `applyGridProposal` |
| Keyboard preview is transient | controlled layout contract | `WidgetGrid` renders local previews while the host receives serialisable preview/commit/cancel callbacks; persistence remains host-owned |
