# D6.1 — funnel family

## Objective

Ship an explicit, pure funnel planner and hook-free renderer for ordered non-negative stage values.
The responsive contract follows the locked ladder: Tile replaces the plot with overall conversion,
Strip transposes to horizontal bars, Panel shows the vertical funnel with stage names and values,
Canvas adds per-stage drop-off deltas, and Stage adds absolute/relative conversion plus a per-stage
breakdown. The implementation uses the existing serialisable `Series[]` input and rejects negative
values or ambiguous multi-series funnel data rather than silently changing the meaning.

## Decisions and assumptions

| Item | Class | Evidence | Effect |
|---|---|---|---|
| Funnel stages are ordered by canonical x and represented by one non-empty Series | Implementation contract | Existing `Series[]` and data identity rules | Multi-series and duplicate stage inputs fail explicitly rather than choosing a silent aggregation |
| Tile uses an overall conversion summary; Strip uses horizontal stage bars; Panel is vertical; Canvas adds drop-off; Stage adds relative conversion and breakdown | Locked responsive source | `research/10-responsive-ladder.md` §4 Funnel | Planner changes information content by rung rather than only resizing the same shape |
| Conversion is current stage value divided by the first finite stage value; drop-off is the non-negative relative loss from the previous stage | Explicit semantic default | Funnel ladder vocabulary; no CR-D15 evidence yet | Zero baseline yields null conversion/drop-off text instead of division-by-zero or fabricated percentages |
| Negative values are invalid for a part-to-whole funnel | Family invariant | Funnel semantics and `R2` launch catalogue | Planner/frame rejects them; no negative-width or inverted stage geometry |
| Any minimum stage width/height is a project-owned geometry default, not a perception claim | Tier C implementation boundary | Existing token/geometry policy | Zero stages remain visible through text/table data; no fabricated value is used to imply a stage |
