## Acceptance criteria

- [ ] New pure core types model active datum identity, active series identity, tooltip mode/open
  state, and legend visibility with no functions, DOM values, Date, Map, Set, or undefined fields.
- [ ] Series identity is keyed by `Series.id`, never by array position; point identity is explicit
  and deterministic for the canonical point sequence.
- [ ] Controlled helpers can create/normalize/update the state without owning data, filters,
  fetching, persistence, or React state.
- [ ] Reordering series, resizing the chart, and toggling visibility do not silently reassign the
  active series/datum or visibility to another series; missing IDs reconcile deterministically.
- [ ] Tests cover JSON round-trip, frozen/serialisable output, stable identity through reorder and
  resize-like updates, legend visibility, tooltip modes, null active state, and invalid/duplicate
  identity inputs.
- [ ] Core typecheck, focused tests, core lint/dependency boundary, and `git diff --check` pass.
