## Objective

Create a small immutable seam for family-local planners and mark renderers while preserving the
existing line/area plan and SVG output. The seam must be statically analyzable, RSC-safe, and
tree-shakeable without exposing a mutable plugin API.

## Implementation

- Added the generic FamilyPlanner, PlannerRegistration, BuiltInPlannerRegistry, and mark-renderer
  contracts. Planner functions and renderer functions stay implementation-local; only ChartPlan and
  frame data cross the core-to-renderer boundary.
- Added the family-local line planner adapter and the frozen built-in planner table. planChart now
  dispatches through that table and retains its prior unsupported-type error.
- Added the family-local line mark renderer and frozen renderer table. Chart now dispatches marks
  through the table while retaining the prior element order and unsupported-mark error.
- Added immutable registration, line/area equivalence, serializability, renderer output, and
  unsupported-input tests.
- Added packages/core/src/families/README.md with the add-a-family checklist and deterministic
  fixture convention. No future family behavior is claimed.
