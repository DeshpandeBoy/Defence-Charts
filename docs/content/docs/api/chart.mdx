---
title: Chart
description: Hook-free rendering for a plan, canonical values, and the same SizeContext.
---

```tsx
import { Chart } from '@gx/primitives'
```

`Chart` is state-free, effect-free, and ref-free. It can render in a React Server Component with no
GX client bundle.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `plan` | `ChartPlan` | Yes | The complete render contract |
| `data` | `readonly Series[]` | Yes | Values used to resolve scales and coordinates |
| `ctx` | `SizeContext` | Yes | The exact object that produced the plan |
| `title` | `string` | Yes | Accessible name |
| `description` | `string` | No | Accessible description |
| `policy` | `Partial<PlanPolicy>` | No | Must match the plan's policy |
| `id` | `string` | No | Stable ID prefix |
| `className` | `string` | No | Figure class |

## Render tree

```text
figure.gx-chart
|- svg[role="graphics-document"]
|  |- title / desc
|  |- grid, marks, axes, labels, value display
|- figcaption
   |- HTML data table when the plan includes it
```

The root SVG never uses `role="img"`; that role would make its descendants presentational. Ticks
and gridlines use CSS-settable rectangles instead of SVG `<line>` coordinates.

## Current renderer scope

For the implemented line/area, bar/timebar, donut, scatter, KPI, progress, heatmap, and funnel families,
`<Chart>` renders the registered mark geometry, labels, axes, gridlines, target-aware value
displays, heatmap cell intensity metadata, ordered funnel stage conversion/drop-off text, and
optional HTML data tables. Funnel input is one series of ordered, finite non-negative stage values;
invalid or ambiguous input fails explicitly rather than silently drawing a line chart for another
type.

At A6, ticks and gridlines are keyed by domain value so an existing guide can keep its identity
when its pixel position or tick count changes. This is what makes the CSS transition meaningful;
newly mounted marks still rely on `AutoChart`'s deadband for resize stability.
