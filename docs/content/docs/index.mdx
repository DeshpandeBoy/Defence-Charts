ShiftCharts is a presentational React chart library built around a **responsive information ladder**.
When a widget gets smaller, ShiftCharts can remove an unreadable axis, replace a line with a horizon
encoding, move a legend, or state one value directly. It does not merely squeeze the same chart.

The current implementation includes the responsive planner, controlled dashboard grid, interaction
layer, and the Free-v1 chart catalogue: line, area, bar/timebar, donut, KPI, progress, scatter,
heatmap, and funnel.

## The whole system in one path

| Owner | Receives | Produces |
| --- | --- | --- |
| Your application | API rows, query results, local state | Canonical `Series[]` |
| `@shiftcharts/core` | Size, data shape, policy, overrides | Serializable `ChartPlan` |
| `@shiftcharts/primitives` | Plan, canonical values, same size context | Accessible SVG and data table |
| `@shiftcharts/react` | A container with a real size | Measurement, planning, then `<Chart>` |

The planner never sees actual values. `describeShape(data)` derives the counts and traits it
needs; `resolveFrame(plan, data, ctx)` is where values become scales and coordinates.
