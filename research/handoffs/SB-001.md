## Decisions and assumptions

| Item | Class | Effect |
|---|---|---|
| Separate `apps/sandbox` app | user request | Prevents sandbox controls and state from interfering with the existing playground. |
| Static `<Chart>` preview with `planChart()` | architecture | Keeps the preview directly coupled to the pure core plan and avoids a second responsive implementation. |
| CSS token overrides are scoped to the sandbox root | architecture | Lets users experiment with presentation without modifying token source or global theme state. |
| Raw JSON editors remain available beside quick controls | implementation | Preserves access to the full serialisable policy/override/data surface while keeping common changes discoverable. |
