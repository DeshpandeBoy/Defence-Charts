      the shipped fixture), not 0. Fix `fitValueDisplay()`'s `'donut-total'` mode (or `frame.ts`'s
      `seriesFrame()`) to compute the aggregate independent of whether arc geometry was built for the
      rung. Also widen `scripts/check-family-matrix.mjs`'s donut assertion (~L184) so it checks Micro
      too — currently scoped `card.rung !== 'micro'`, which is why this stayed green.
- [ ] **VT-002**: funnel Micro shows a labelled conversion figure (matching Tile's "Overall
      conversion: N%" wording/computation), not a bare unlabelled number.
- [ ] **VT-004**: a heatmap cell with a negative value never resolves to the same
      `data-heatmap-intensity` (and the same computed `fill`/`fill-opacity`) as a true-zero cell.
      Extend `packages/core/src/heatmap-frame.test.ts` with a dataset containing both a zero and a
      negative value asserting they bucket differently.
- [ ] **VT-005 / VT-006**: direct end-of-line/in-plot value labels do not visually overlap at Panel,
      Canvas, or Stage for the shipped 6-series crossing fixture — either a collision-avoidance pass
      within the size budget, or a drop to an overflow/occlusion marker consistent with the existing
      "+N" pattern used elsewhere. Add a geometry test asserting no mutual label-rect overlap for this
      fixture at these rungs.
- [ ] **VT-007**: at narrow width (390px), heatmap's first x-axis tick label does not collide with its
      neighbour (e.g. consistent "Jan 01"-style formatting instead of switching to year-only, or one
      fewer tick below a width threshold). Extend `check-family-matrix.mjs`'s narrow-viewport pass
      with an adjacent-axis-tick-label overlap check.
- [ ] **VT-008**: `.gx-arc` fill colour varies per slice (add `[data-slice-index]`-keyed colour rules
      mirroring the existing `[data-series-index]` pattern), and the Panel compact key reads the same
      per-slice colour source instead of independently cycling by series-index position. Add a
      static-render test asserting N distinct `.gx-arc` fill values for an N-category donut, plus a
      cross-check that compact-key/legend swatch colour for slice *i* equals arc *i*'s own colour.
- [ ] None of the above fixes regress `D0.2-chart-information.md`'s or
      `D0.2-information-preservation.md`'s prior fixes — rerun the full matrix gate and full test
      suite, not just the new assertions.
