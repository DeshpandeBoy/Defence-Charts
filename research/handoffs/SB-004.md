# SB-004 — Core bar geometry polish

## Objective

Improve the shared bar-chart geometry and presentation so bar/tooltips/legends remain visually
coherent across sizes: tooltip colour follows the active series, bars support rounded corners,
legend placement is legible and consistently separated from the plot, and the resolved chart box
does not reserve asymmetric space or clip its right edge.

## Acceptance criteria

- [x] Bar rectangles support a token-backed radius without changing stable cell identity, and the
      radius remains bounded by each bar's width/height and baseline direction.
- [x] Tooltip rows expose the same series colour identity as the active bar/series marks in light,
      dark, and forced-colors-safe states; no hard-coded colour is introduced.
- [x] Legend placement has a clear, reserved relationship to the bar plot at compact and larger
      sizes;
      it does not visually blend into marks or create asymmetric plot padding.
- [x] Bar charts use balanced left/right plot containment at the sandbox's wide and narrow sizes;
      SVG geometry and end labels stay inside their measured chart box with no horizontal overflow.
- [x] Add focused regression proof for geometry, radius bounds, tooltip colour identity, legend
      placement, and right-edge containment; preserve existing identity/accessibility contracts.
- [x] Run focused tests, relevant browser family checks, `git diff --check`, and record exact output.
- [x] Documentation describes only shipped behavior; no product docs required a change.
