# E1.1 — Build the built artifact contract

## Objective

Make published package exports resolve to built JavaScript/declarations and emit/copy every
documented CSS subpath into `dist`, with a no-network packed-consumer proof.

## Implementation

- Enabled `tsdown` `exports.devExports: true` in every package config. Workspace `exports` remain
  source-facing after a build, while `publishConfig.exports` is generated with `dist` targets.
- Added `scripts/emit-package-assets.mjs` as the shared CSS registry, tsdown export callback, and
  post-build copier.
- Added CSS emission to the four CSS-bearing package build scripts:
  - `@gx/grid`: `widget-shell.css`, `widget-states.css`, `keyboard-grid.css`
  - `@gx/primitives`: `chart.css`
  - `@gx/react`: `auto-chart.css`
  - `@gx/tokens`: `themes/theme.css` plus its `themes/typography.css` import dependency
- Kept CSS-bearing package `sideEffects` declarations accurate; `@gx/tokens` uses `**/*.css`
  because its emitted CSS remains nested under `dist/themes/`.
- Added `scripts/check-built-artifacts.mjs` and its Vitest test. The check reads package manifests,
  verifies existing JS/declaration/CSS targets, packs all six packages with local offline pnpm,
  extracts them into a temporary consumer, resolves every public JS/declaration/CSS entrypoint,
  and imports the five runtime packages without an install.
