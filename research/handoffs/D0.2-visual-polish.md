## Acceptance criteria

- The six size rungs have visibly different chart-frame proportions and information hierarchy.
- Micro, Tile, and Strip remain readable and do not inherit the old generic frame height.
- Card headers read like compact reports: clear title, rung context, mark/interaction metadata, and
  a restrained table disclosure surface.
- The visual language uses the existing neutral theme and token variables; no second styling system
  or runtime behavior is introduced.
- Light theme, forced colors, reduced motion, and existing static accessibility output remain intact.
- Run playground typecheck, focused family-matrix tests, browser matrix verification, and `git diff --check`.

## Current evidence

The captured baseline page showed every rung at a 224px chart-frame height, including
`line-micro`, `line-tile`, `line-strip`, `line-panel`, `kpi-micro`, and `donut-tile`. The full-page
visual was a long two-column gallery with weak card hierarchy and insufficiently differentiated
narrow-rung information surfaces.

The implementation now uses a three-column report-card gallery at desktop widths, compact card
headers with rung/mark/interaction metadata, a data/readout summary row, quiet rule borders, and
explicit chart-frame heights of 84px, 112px, 128px, 176px, 240px, and 304px for Micro through
Stage. Grid items are top-aligned so their card boxes retain the ladder rather than stretching to
the tallest item in a row.
